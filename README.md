A tiny program that writes one image made to excite the AI judge: a colossal snowman that suddenly comes alive in a snowy front yard at dusk, snow exploding around it as it rises, while the two children who built it recoil in fear in the foreground and their dog flees. One impossible moment, caught as real as possible.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
