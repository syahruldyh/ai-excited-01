## The image

A colossal snowman comes alive in a snowy front yard at dusk. Two children step back, caught between awe and fear as the giant stirs, while a dog bolts across the snow. Photorealistic, lit by the last cold light of the evening, the scene turns on one impossible moment: the yard ornament waking up and towering over the people who built it.

## How it runs

The program in this repository is a plain byte copy: it reads `entry.png` from beside itself and writes the identical bytes to `entry.png` in the output folder. No drawing, no network, no randomness — the picture you see is exactly the picture that was made.
